# منطقة الصفر — Zero Zone

لعبة **باتل رويال ثلاثية الأبعاد بمنظور الشخص الثالث** لسطح المكتب، مبنية بـ Electron و Three.js.
تجمع أفكاراً من PUBG و Call of Duty و Battlefield في قوانين خاصة بها:
50 لاعباً يقفزون من طائرة فوق جزيرة، يجمعون الأسلحة والدروع، والمنطقة الآمنة تضيق… ويبقى ناجٍ واحد فقط.

## قوانين منطقة الصفر

| الفكرة | مستوحاة من | كيف تعمل عندنا |
| --- | --- | --- |
| القفز والغنائم والمنطقة الزرقاء | PUBG | قفز حر من الطائرة، دروع بثلاثة مستويات، ومنطقة تضيق على 7 مراحل |
| **الفرصة الثانية** | Call of Duty: Warzone | إذا سقطت قبل المرحلة الرابعة تُنقل إلى الحلبة لمبارزة واحد لواحد بنفس السلاح ضد آخر لاعب سقط — الفائز يعود بالمظلة |
| **طائرة الاستطلاع** | Call of Duty | كل 3 قتلى تكشف مواقع الأعداء على الخريطة لمدة 25 ثانية |
| **الانزلاق** | Call of Duty | أثناء الركض اضغط `C` (انحناء) لانزلاق سريع ومنخفض |
| **الدمار** | Battlefield | القنابل تفتح ثغرات في جدران المباني وتحطم الصناديق |

## الجديد في هذا الإصدار

- **لوبي ثلاثي الأبعاد** بساحة ليلية عربية الطابع (أقواس، نخيل، فوانيس، هلال) وشخصيتك في الوسط، مع زر «ابدأ» وبطاقة الوضع (كلاسيكي — فردي) وتبويبات: الإحصائيات، المظهر، طريقة اللعب، الإعدادات. بدون فرق أو تعاون.
- **خريطة 8×8** (مربعات شبكة كل منها «1 كم» على الخريطة): جزيرة رئيسية بتلال ونهر يعبرها، وجزيرة جنوبية للقاعدة العسكرية، وجسور، وشواطئ وبحر لا يمكن السباحة فيه بعيداً.
- **رسوميات محسّنة**: تضاريس مرتفعة ومنخفضة، سماء وغيوم وشمس، ماء، جدران بنوافذ وأسقف مائلة، نوعان من الأشجار، عشب قرب اللاعب، وجنود بتفاصيل أكثر.
- **قفز مثل ألعاب الباتل رويال**: سقوط حر ثم مظلة (تُفتح تلقائياً أو بالزر)، مع مقياس الارتفاع والسرعة، وبوصلة، وأسماء المدن ظاهرة في السماء.
- **أزرار تحكم على الشاشة** (مثل ألعاب الجوال): عصا حركة مع تثبيت الركض، سحب للنظر، زرّا إطلاق، منظار، تلقيم، قفز، انحناء، انبطاح، قنبلة، علاج، وزر سياقي. ويمكن التبديل إلى لوحة المفاتيح والفأرة.
- **الوقفات**: انحناء وانبطاح يقللان السرعة ويزيدان الدقة ويصعّبان رؤيتك على الخصوم، والتلال تحجب الرؤية والرصاص.

## المميزات

- **عالم ثلاثي الأبعاد**: كاميرا خلف الكتف، نظر بالفأرة، ظلال، ضباب، بحر وشاطئ، ومنظار حقيقي للقناصات.

- **القفز من الطائرة**: مسار طيران عشوائي فوق الجزيرة، تختار مكان القفز وتوجّه المظلة بنفسك.
- **جزيرة مولّدة عشوائياً** في كل مباراة: مدن وقرى بأسماء، قاعدة عسكرية فيها غنائم أقوى، طرق، غابات، صخور، صناديق وحاويات. المباني لها أبواب وأسقف تخفي ما بداخلها.
- **49 خصماً بالذكاء الاصطناعي**: يقفزون إلى أماكن مختلفة، يجمعون الغنائم، يتحصنون في المباني، يسمعون إطلاق النار، يتحركون مع المنطقة، يعالجون أنفسهم، ويقاتلون بعضهم وإياك. لكل منهم مستوى مهارة وشخصية (حذر أو هجومي).
- **المنطقة الزرقاء**: 7 مراحل؛ الدائرة البيضاء تُظهر المنطقة الآمنة القادمة، والضرر يزداد مع كل مرحلة.
- **12 سلاحاً** بأنواع ذخيرة مختلفة: مسدس P92، رشاشات UMP45 وVector، بنادق S1897 وS12K، بنادق هجومية M416 وSCAR-L وAKM، Mini14، قناصة Kar98k — ومن الإنزال الجوي فقط: AWM وM249.
- **التصويب بالمنظار** (زر الفأرة الأيمن): رؤية أبعد ودقة أعلى حسب السلاح.
- **دروع وحقائب** بثلاثة مستويات: خوذة تحمي من طلقات الرأس، سترة تخفف ضرر الجسد، وحقيبة تزيد السعة.
- **العلاج والطاقة**: ضمادات، إسعاف أولي، حقيبة طبية، مشروب طاقة ومسكّن (شفاء تدريجي وسرعة أعلى).
- **قنابل يدوية** ترتد عن الجدران.
- **إنزالات جوية** بدخان أحمر تحوي أقوى الأسلحة ودروع المستوى 3.
- خريطة مصغّرة، خريطة كاملة مع علامات، سجل القتلى، مؤشر اتجاه الضرر، علامة الإصابة، والتقاط تلقائي للذخيرة والأدوية والدروع الأفضل.
- ثلاثة مستويات صعوبة، وإحصاءات محفوظة (انتصارات، أفضل ترتيب، مجموع القتلى).
- مؤثرات صوتية مولّدة برمجياً — بدون أي ملفات خارجية.

## التحكم

| المفتاح | الوظيفة |
| --- | --- |
| الفأرة | النظر والتصويب (انقر داخل اللعبة لتثبيت المؤشر) |
| `F` | القفز من الطائرة / فتح المظلة / التقاط أقرب غرض |
| `W A S D` / الأسهم | الحركة وتوجيه المظلة |
| `Shift` | الركض السريع |
| `C` / `Z` / `Space` | انحناء (وأثناء الركض: انزلاق) / انبطاح / قفز |
| زر الفأرة الأيسر | إطلاق النار |
| زر الفأرة الأيمن | التصويب بالمنظار |
| `R` | إعادة التلقيم |
| `1` `2` `3` / العجلة | تبديل السلاح — `X` لإخفائه |
| `4` `5` `6` `7` `8` | ضمادة، إسعاف أولي، حقيبة طبية، مشروب طاقة، مسكّن |
| `G` | رمي قنبلة نحو المؤشر |
| `M` / `Tab` | الخريطة الكاملة (انقر لوضع علامة) |
| `Esc` | إيقاف مؤقت (ويحرر المؤشر) |
| `N` | كتم الصوت |
| `F11` | ملء الشاشة |

## التشغيل

```bash
npm install
npm start
```

## بناء نسخة قابلة للتثبيت

```bash
npm run dist        # للنظام الحالي
npm run dist:win    # Windows (NSIS)
npm run dist:linux  # Linux (AppImage)
npm run dist:mac    # macOS (DMG)
```

تظهر الملفات الناتجة في مجلد `dist/`.

## بنية المشروع

```
main.js          نقطة دخول Electron (النافذة الرئيسية)
src/index.html   الواجهة والقوائم
src/style.css    التنسيق
src/audio.js     المؤثرات الصوتية (Web Audio)
src/render3d.js  الرسم ثلاثي الأبعاد بـ Three.js (التضاريس، المباني، الأشجار، الشخصيات، المنطقة…)
src/lobby3d.js   مشهد اللوبي ثلاثي الأبعاد
src/touch.js     أزرار التحكم على الشاشة
src/vendor/      مكتبة Three.js (رخصة MIT)
src/data.js      الأسلحة والذخيرة والدروع والأدوية وجداول الغنائم ومراحل المنطقة
src/map.js       توليد الجزيرة، التصادم، خط الرؤية، ورسم الخريطة
src/ai.js        سلوك الخصوم (الإدراك، الغنائم، التنقل عبر الأبواب، القتال، المنطقة)
src/game.js      حلقة اللعبة، الطائرة والمظلات، القتال، الواجهة، الخرائط
```

يمكن أيضاً فتح `src/index.html` مباشرة في المتصفح للتجربة السريعة.

### خيارات التطوير

تُضاف إلى رابط الصفحة، مثل `index.html?speed=4&god=1`:

- `speed=N` تسريع الزمن (للاختبار).
- `god=1` لاعب لا يتلقى ضرراً.
- `seed=N` توليد نفس الجزيرة.
- `bots=N` عدد الخصوم.
- `debug=1` كشف حالة اللعبة في `window.__G`.
- `norender=1` تشغيل المحاكاة بدون رسم ثلاثي الأبعاد (للاختبارات الطويلة).

> تحتاج اللعبة إلى كرت شاشة يدعم WebGL (كل الأجهزة الحديثة تقريباً).
