# منطقة الصفر — Zero Zone

لعبة بقاء وتصويب من منظور علوي (Top-down Shooter) لسطح المكتب مبنية بـ Electron.
ابقَ داخل **المنطقة الآمنة** التي تتقلص مع كل موجة، واصمد أمام موجات متزايدة من الأعداء.

## المميزات

- موجات أعداء لا نهائية تزداد صعوبتها تدريجياً.
- منطقة آمنة تتقلص وتنتقل بين الموجات — البقاء خارجها يستنزف صحتك.
- ثلاثة أسلحة: **مسدس** (ذخيرة لا نهائية)، **رشاش**، **خرطوش** — تُجمع من صناديق الإمداد.
- أربعة أنواع من الأعداء: العدّاء، الضخم، القنّاص، و**الحارس** (زعيم يظهر كل خمس موجات).
- اندفاع سريع مع حصانة لحظية، ومضاعف نقاط للقتل المتتالي.
- مؤثرات صوتية مولّدة برمجياً (بدون ملفات صوت)، جزيئات، اهتزاز الشاشة، وخريطة مصغّرة.
- واجهة عربية بالكامل وحفظ أفضل نتيجة.

## التحكم

| المفتاح | الوظيفة |
| --- | --- |
| `W A S D` / الأسهم | الحركة |
| الفأرة | التصويب |
| زر الفأرة الأيسر | إطلاق النار (اضغط مطولاً) |
| `R` | إعادة التلقيم |
| `1` `2` `3` / عجلة الفأرة | تبديل السلاح |
| `Shift` / `Space` | اندفاع |
| `Esc` / `P` | إيقاف مؤقت |
| `M` | كتم الصوت |
| `F11` | ملء الشاشة |

## التشغيل

```bash
npm install
npm start
```

## بناء نسخة قابلة للتثبيت

```bash
npm run dist        # للنظام الحالي
npm run dist:win    # Windows (NSIS)
npm run dist:linux  # Linux (AppImage)
npm run dist:mac    # macOS (DMG)
```

تظهر الملفات الناتجة في مجلد `dist/`.

## بنية المشروع

```
main.js          نقطة دخول Electron (النافذة الرئيسية)
src/index.html   الواجهة والقوائم
src/style.css    التنسيق
src/audio.js     المؤثرات الصوتية (Web Audio)
src/game.js      منطق اللعبة والرسم
```

يمكن أيضاً فتح `src/index.html` مباشرة في المتصفح للتجربة السريعة.
للاختبار يمكن البدء من موجة معيّنة عبر `index.html?wave=5`.
